# Cloud Cost Estimator

Cloud Cost Estimator — multi-cloud compute & serverless price comparison across AWS, Azure and GCP. Part of the Zion Tech Group App Network.

**Live app:** https://ziontechgroup.com/cloud-cost-estimator/

## About
Cloud Cost Estimator is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (700+ open-source AI & IT ops apps). Category: **FinOps & Cloud Tools**.

## Features
- Side-by-side compute, storage and serverless pricing across AWS/Azure/GCP
- Right-sizing hints for over-provisioned workloads
- Region and commitment (RI/Savings Plan) comparisons
- Exportable estimates for budget reviews
